# 日志页多维过滤 · 界面 Before / After

同一场景（面板「日志」页读同一条日志文件）、同一视口（1440×900）、同一主题（浅色 / 深色各一组）。

| 截图 | 说明 |
|-|-|
| `before-logs-light.png` | 改造前（浅色）：工具栏只有级别筛选与关键字搜索，看不出事件属于哪个域、也串不出同一条链路 |
| `after-logs-light.png` | 改造后（浅色）：工具栏多出「域 / 动作 / 追踪」三个维度，与级别、关键字取交集 |
| `before-logs-dark.png` | 改造前（深色）：同场景的深色基线 |
| `after-logs-dark.png` | 改造后（深色）：同场景的深色改动版 |
| `after-logs-filter-trace.png` | 改造后：追踪选 `tk-84`，只剩这条工单链路上的 9 条日志；级别计数同步收敛为该链路的条数 |

截图取自真实构建产物（`pnpm build:web`）与真实日志读取实现（`readLogs`），
日志文件内容由服务日志实现（`createLogger`）写出，不含真实用户数据与凭据。
