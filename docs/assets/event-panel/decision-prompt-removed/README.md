# 删除旧版全局 prompt · Web 面板界面 Before / After

同一视口（1440×900 @1x）、同一主题（浅色）、同一份配置（`events.rules` 为空）。

| 截图 | 说明 |
|-|-|
| `decision-before.png` | 改造前：「判定方式与全局兜底」里有「旧版全局 prompt」文本域与「未匹配规则时使用全局 prompt」开关 |
| `decision-after.png` | 改造后：只剩「判定方式 / 置信度阈值 / 判定失败兜底」三项，判定依据统一在决策规则里 |
| `rule-modal-before.png` | 改造前：规则编辑弹窗的阈值区是三列，`autoRun` 在最右边，但判定逻辑从不读它（autorun 是 choice 题，不是打分题） |
| `rule-modal-after.png` | 改造后：阈值只剩 `isValid` 与 `projectPick` 两列，都是真正参与判定的 |

界面改动说明：

- 删掉「旧版全局 prompt」文本域与「未匹配规则时使用全局 prompt」开关：这两个配置项已彻底删除，未匹配规则的事件一律保持未判定。
- 删掉 `autoRun 阈值`：它从规则体系落地起就没有任何判定逻辑读取，是个只写不读的旋钮。
- 分组标题从「判定方式与全局兜底」改成「判定方式与兜底」，说明文字同步改成「判定依据在每条决策规则里」。
