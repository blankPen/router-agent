# 事件总线 · Web 面板「事件」页签 · 界面 Before / After

同一场景（Web 面板新增「事件」页签）、同一视口（1440×1000 @1x）、同一主题（深色）。

基线：改动前的 `ra/tk-86-llm`；改动版本：分支 `ra/tk-87-设计多来源事件总线方案并输出飞书文档-2`（本轮新增事件总线）。截图取自本地真实运行的服务（`node dist/cli/main.js start --foreground --no-open`），配置内容为占位值（`oc_demo_ops` / `router-agent`），未包含任何真实密钥、群 id 或用户数据。

| 截图 | 说明 |
|-|-|
| `before.png` | 改造前：面板顶部只有「工单 / 群 / 配置 / 日志」等页签，没有事件入口；事件只能靠飞书消息进入系统 |
| `after.png` | 改造后：顶部新增「事件」页签，页面包含三块：① 统计卡（总数 / 待处理 / 待审核 / 24h）；② 事件来源订阅卡片（GitHub Issue / HTTP Webhook / 定时任务 / 飞书）与决策 prompt 编辑器入口；③ 事件队列表格（支持 P0–P4 优先级筛选，待审核行可直接批准 / 驳回 / 延后 / 忽略 / 重试） |

审批动作对应后端 `POST /api/events/:id/action`，批准后由事件总线直接派生工单并复用现有派工链路。
